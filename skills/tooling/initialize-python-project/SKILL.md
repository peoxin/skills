# Initialize Python Project

Initialize the current directory as a new Python project with `uv`, add Ruff as a development dependency, and apply the fixed Ruff and `.gitignore` defaults.

## Preconditions

1. Check that `uv` is available on `PATH`. If it is unavailable, stop.
2. Inspect the current directory. Treat an existing `pyproject.toml` as an initialized Python project; stop and preserve it. Existing unrelated files do not by themselves block initialization.
3. Ask the user which Python version `uv` should use. Do not infer or silently choose a version.

## Workflow

1. Run `uv init --python <python>` to initialize the current directory as a new Python project.
2. Append the fixed Ruff configuration to `pyproject.toml`. Preserve all fields generated by `uv`.
3. Replace `.gitignore` with the fixed template, whether or not a `.gitignore` already exists.
4. Run `uv add --dev ruff` to add Ruff as a development dependency. If this fails, report the failure.

## Templates

### Ruff Configuration

```toml
[tool.ruff]
line-length = 120

[tool.ruff.lint]
select = [
  "E",    # pycodestyle errors
  "W",    # pycodestyle warnings
  "F",    # pyflakes
  "I",    # isort
  "B",    # flake8-bugbear
  "C4",   # flake8-comprehensions
  "UP",   # pyupgrade
  "SIM",  # flake8-simplify
]
ignore = ["E501"]  # line length handled by formatter

[tool.ruff.format]
quote-style = "double"
indent-style = "space"
```

### Git Ignore

```gitignore
# Python-generated files
__pycache__/
*.py[oc]
build/
dist/
wheels/
*.egg-info

# Virtual environments
.venv

# Tool caches
.pyright/
.ruff_cache/
.mypy_cache/
.pytest_cache/

# Editors and operating systems
.vscode/

```
