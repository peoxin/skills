# Co-locate Reference Records and Artifacts

Reference investigation uses one directory per Reference, with `reference.yaml` beside retained artifacts and an `artifacts` list for both retained files and external materials. `$search-references` only presents candidates and hands explicit selections to `$add-references`, which reads direct sources and writes the current record shape without lifecycle status; complete repositories, datasets, and model weights remain external. This layout keeps multi-file provenance local and makes acquisition explicit, at the cost of abandoning the superseded flat and status-bearing formats during early development.
