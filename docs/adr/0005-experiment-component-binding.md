# Bind Experiment Components Through One Control Commit

An Experiment is a concrete definition rather than a reusable component. Its `EXPERIMENT.md` records component paths, environment configuration paths, and phase behavior. Immediately before a formal run, `run-experiment` fixes the Experiment and its declared same-repository dependency closure in one user-confirmed control commit. The commit tree includes the Experiment directory, selected Model, Dataset derivations, Benchmark, their declared specifications, implementations, configurations, checks, and same-repository environment paths.

A same-repository component is identified by the repository, the complete Experiment control commit SHA, and its path. External repositories remain identified by immutable commit SHA and paths; external environments and other resources use immutable locators and digests. `EXPERIMENT.md` does not record its own future SHA. The commit message names the Experiment and summarizes component paths and external immutable identities, but the commit tree and declared records are authoritative.

The default submission set is the Experiment and its declared dependency closure. `run-experiment` checks explicit local paths and entry points for obvious undeclared references, stops for clarification when needed, shows the exact diff, paths, and commit message, and creates the control commit only after explicit confirmation. The user may add paths but may not remove declared dependencies. If there are no changes, the current `HEAD` may be reused only when its tree contains the complete closure.

After selecting the control commit, `run-experiment` requires `HEAD` to remain that commit and the worktree to be clean before running. It then uses the current worktree and the declared environment, phases, commands, resources, checkpoints, and outputs. Component skills do not create commits, and user-created component commits are ordinary history rather than execution prerequisites. Run outputs remain outside the control commit and may be retained later through a user-created Result commit.
